# 2 Blake Lane — OSP Signature Property Collection

Public luxury-property presentation for 2 Blake Lane, The Hancock, at Bull Point Plantation.

The buyer-facing site includes the approved architectural renderings, furnished floor plans, selection collection, Zillow listing, buyer brochure, one-tap SMS actions, approved-information property concierge, brokerage attribution and buyer disclosures.

The repository is also the working model for future OSP listing microsites:

- `listing-data.json` records the verified property facts, contacts, links and approved assets.
- `OSP_LISTING_LAUNCH_GUIDE.md` contains the repeatable intake, production, DNS and launch checklist.
- `CNAME` reserves the branded property hostname.

Public address: `https://2blakelane.osprealestate.com`
